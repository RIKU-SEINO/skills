# personal-skills

個人用の Claude Code スキル集。

## 使い方

```
git clone <このリポジトリ> ~/personal-skills
ln -s ~/personal-skills/<スキル名> ~/.claude/skills/<スキル名>
```

## スキル

| スキル | 内容 |
|---|---|
| draw-diagram | 構成図・シーケンス図を Mermaid で描き、VS Code 同梱の Mermaid ＋ headless Chrome で PNG にして ~/dev/diagrams に保存する（macOS、VS Code、Google Chrome が必要） |
